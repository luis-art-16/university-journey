# 🗄️ Fundamentos de Bases de Dados

**Ano:** 2º Ano | **Semestre:** 2º Semestre  
**Linguagem / SGBD:** SQL (PostgreSQL / MySQL / SQLite / Oracle)

## 📌 Sobre a Cadeira
Unidade curricular dedicada à conceção, Modelação e implementação de sistemas de bases de dados relacionais. Abrange desde a fase conceptual (Modelo Entidade-Associação) até à implementação física e manipulação de dados avançada em SQL.

## 🎯 Principais Tópicos Abordados
* **Modelação Conceptual:**
  * Diagramas Entidade-Associação (ER / EER): entidades, atributos, cardinalidades e relações.
* **Modelo Relacional:**
  * Mapeamento de modelos ER para esquemas relacionais.
  * Chaves primárias (PK), chaves estrangeiras (FK) e restrições de integridade.
* **Álgebra Relacional:**
  * Operadores fundamentais: Seleção ($\sigma$), Projeção ($\pi$), Junção ($\bowtie$), União ($\cup$), Interseção ($\cap$), Diferença ($-$).
* **Linguagem SQL (Structured Query Language):**
  * **DDL (Data Definition Language):** `CREATE`, `ALTER`, `DROP`.
  * **DML (Data Manipulation Language):** `INSERT`, `UPDATE`, `DELETE`.
  * **DQL (Data Query Language):** Consultas simples e complexas (`SELECT`, `WHERE`, `GROUP BY`, `HAVING`, `ORDER BY`).
  * Junções (`INNER JOIN`, `LEFT/RIGHT OUTER JOIN`, `CROSS JOIN`) e Subconsultas (*Subqueries*).
  * Vistas (*Views*), Gatilhos (*Triggers*) e Procedimentos Armazenados (*Stored Procedures*).
* **Teoria de Normalização:**
  * Dependências funcionais e eliminação de redundâncias.
  * Formas Normais: 1FN, 2FN, 3FN e BCNF (Boyce-Codd).

## 📂 Organização da Pasta
* 📖 **`Teoricas/`:** Diapositivos e resumos teóricos sobre modelação relacional, normalização e álgebra relacional.
* 💻 **`Praticas/`:** Exercícios de consolidação de SQL e álgebra relacional.
* 🛠️ **`Projetos_SQL/`:** Scripts de criação/povoamento de bases de dados (`.sql`) e diagramas de arquitetura de dados.
