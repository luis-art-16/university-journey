# 🧠 Algoritmos e Estruturas de Dados

**Ano:** 1º Ano | **Semestre:** 2º Semestre  

## 📌 Sobre a Cadeira
Esta é uma das unidades curriculares mais fulcrais da ciência da computação. Foca-se no desenho, implementação e análise da eficiência de algoritmos, bem como na abstração e estruturação de dados em memória dinâmica.

## 🎯 Principais Tópicos Abordados
* **Análise de Complexidade:** Notação Big-O ($O(n)$, $O(n^2)$, $O(\log n)$), complexidade temporal e espacial.
* **Memória Dinâmica e Ponteiros:** Alocação de memória em tempo de execução (malloc, calloc, free, realloc) e manipulação avançada de ponteiros.
* **Estruturas de Dados Lineares:**
  * Listas Ligadas (Singly & Doubly Linked Lists).
  * Pilhas (Stacks - LIFO).
  * Filas (Queues - FIFO).
* **Estruturas de Dados Não-Lineares:**
  * Árvores (Trees, Binary Search Trees - BST).
* **Algoritmos de Pesquisa e Ordenação:**
  * Pesquisa Linear e Binária.
  * Sorting (Bubble Sort, Insertion Sort, Selection Sort, Merge Sort, QuickSort).

## 📂 Organização do Repositório
* 📖 **`Aulas/`:** Diapositivos teóricos (Aula 2 a 11) e sumários cobrindo os fundamentos teóricos de estruturas de dados e algoritmos.

## 🛠️ Tecnologias e Ferramentas
* **Linguagem Base:** C / C++ (Foco em manipulação de memória)
